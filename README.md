# Perú TV

Aplicación nativa Android de televisión y radio peruana en vivo.

## Características

- Canales de TV peruana en vivo (TV Perú, TV Perú Noticias, Canal IPe, etc.)
- Radios peruanas (Radio Nacional, PBO, Disney Perú y más)
- Películas de dominio público y demos
- Reproductor ExoPlayer (Media3) con soporte HLS/DASH y Widevine DRM
- Interfaz moderna con Jetpack Compose
- Planes de acceso (Básico / Estándar / Premium) con pago Yape
- Actualización automática mediante GitHub Releases

## Generar APK

1. Ir a **Actions** → **Build and Release APK**
2. Ejecutar **Run workflow**
3. Descargar el artefacto o la Release generada

## Planes

| Plan     | Precio | Acceso              |
|----------|--------|---------------------|
| Básico   | S/ 10  | Radios              |
| Estándar | S/ 25  | Radios + TV         |
| Premium  | S/ 45  | Todo (incluye películas premium) |

Pago vía **Yape 955238172** (aprobación manual por el propietario).

## Nota importante

Los streams incluidos son de demostración o de dominio público. Reemplace las URLs en `MediaRepository` por fuentes con derechos de uso legítimos.
